# Security Policy

Please do not open public issues for security problems. Report them privately via
[GitHub private vulnerability reporting](https://github.com/agenticworkflowprotocol/awp-editor/security/advisories/new)
or to info@agenticworkflowprotocol.org.

In scope: markup or script injection from manifest content, share links or `?url=`, requests to
other origins that the user did not trigger, a view that shows an action as denied or approved when
the manifest says otherwise, and the website.
Validation problems belong to the
[validator](https://github.com/agenticworkflowprotocol/awp-validator/security/policy); problems in
the specification follow the
[specification's policy](https://github.com/agenticworkflowprotocol/agenticworkflowprotocol.org/blob/main/SECURITY.md).

Only the latest release receives fixes until `1.0.0`.
